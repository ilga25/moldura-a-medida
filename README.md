# Moldura a Medida
Calculadora de rectángulos decorativos de moldura: una o dos filas, geometría exterior/interior, lista de piezas y reparto orientativo por barras (first fit decreasing, no óptimo garantizado).

Sitio estático sin dependencias. GitHub Pages desde main, raíz. https://ilga25.github.io/moldura-a-medida/
Pruebas: node check.cjs. Medidas en cm; cortes a punta larga; cada pieza reserva un kerf y cada barra un saneado total. Reserva porcentual sobre metros de piezas, redondeada a barras adicionales.
AdSense integrado, aprobación pendiente. No se garantiza indexación, tráfico ni ingresos. Verificar producto e instalación antes de cortar.
